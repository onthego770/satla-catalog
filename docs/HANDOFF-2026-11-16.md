HISTORY: every change is in the `product_changes` table (who, when, the row before and after); Admin > Item history lists them, and Undo takes back the latest change to an item, photos included (earlier photos are in `photos/history/<change id>/`). THE FILE: Catalog.db is now the master; `Satla_Master_Catalog.csv` is rewritten from it after every change (it gained the columns Bottles per Case, Bottle ml, Pack Source) and `manage.py load-products` refuses to run without `--force`; `manage.py export-products` rewrites the file by hand. THE REFRESH now stores every item of every state (with or without a catalog entry) and its names, so an add or a delete shows at once; which items a state shows is decided in `db.state_products()` (a `catalog_all` state also shows `db.uncataloged()`).
